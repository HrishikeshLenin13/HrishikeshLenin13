# Project directory

A compact map of the repositories in this account. Descriptions refer to repository contents, not production readiness.

## Learning and research

- [Axiom Research](https://github.com/HrishikeshLenin13/AxiomResearch): research community website, volunteer pathways and coursework.
- [Research foundations](https://github.com/HrishikeshLenin13/AxiomResearch-foundations): foundations course website.
- [Aptmark](https://github.com/HrishikeshLenin13/aptmark): local-first adaptive SAT study workspace; content remains subject to editorial review.
- [CalcTutor](https://github.com/HrishikeshLenin13/calctutor): calculator key-by-key instruction and practice.
- [Gradelarp](https://github.com/HrishikeshLenin13/gradelarp): school-reported grades and separate manual planning.
- [Physics2MCQ](https://github.com/HrishikeshLenin13/Physics2MCQ): physics practice application.

## Developer tools and systems

- [Slice](https://github.com/HrishikeshLenin13/slice): Python symbol-dependency context slicing.
- [Slice IDE platform](https://github.com/HrishikeshLenin13/slice-ide-platform): backend components for IDE-oriented slicing.
- [AegisDB](https://github.com/HrishikeshLenin13/AegisDB): educational C++ relational database engine.
- [Atlas](https://github.com/HrishikeshLenin13/Atlas): deterministic distributed runtime and Raft simulation.
- [Helix](https://github.com/HrishikeshLenin13/Helix): optimizing compiler with inspectable passes.

## Browser experiments

- [Lumen](https://github.com/HrishikeshLenin13/Lumen): local browser desktop with notes, calendar and small applications.
- [CreatorPulse](https://github.com/HrishikeshLenin13/creatorpulse): creator analytics dashboard using sample data.

Each project's README is the starting point for setup, limitations and tests.
