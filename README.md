## About

I like turning complicated ideas into practical tools: making research easier to access, helping people learn by doing, and exploring how developer systems can be more precise and useful.

My work ranges from a student research platform to a code-context analyzer, a relational database engine, and interactive learning software. I care about clear interfaces, honest documentation, and showing how a system works—not just what it promises.

## Selected projects

| Project | What it does |
| --- | --- |
| [**Axiom Research**](https://github.com/HrishikeshLenin13/AxiomResearch) | A student-led nonprofit and platform helping high-school students learn research, find mentorship, collaborate, and share work. |
| [**Slice**](https://github.com/HrishikeshLenin13/slice) | A Python code-context tool that builds dependency slices and reports where static analysis cannot prove completeness. |
| [**AegisDB**](https://github.com/HrishikeshLenin13/AegisDB) | A compact relational database engine exploring query planning, storage, transactions, recovery, and measured comparison with SQLite. |
| [**CalcTutor**](https://github.com/HrishikeshLenin13/calctutor) | An interactive calculator tutor that turns written math problems into follow-along keystrokes and explanations. |
| [**Gradelarp**](https://github.com/HrishikeshLenin13/gradelarp) | A grade dashboard and planner with separate school records and manual what-if planning. |
| [**Lumen**](https://github.com/HrishikeshLenin13/Lumen) | A browser-based collection of productivity tools designed to keep its data local. |
